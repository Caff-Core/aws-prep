## The idea in plain language

A shopping centre uses several kinds of protection. Guards at the door turn away troublemakers. Crowd
barriers stop a stampede. Cameras spot suspicious behaviour. Inspectors check for broken locks. A
control room brings it all together.

AWS security services divide the work in the same way. Each has a specific job, and the exam tests
whether you can match the job to the service.

## Keeping attacks out

### AWS WAF

**AWS WAF** is a web application firewall. It inspects HTTP and HTTPS requests and allows or blocks them
according to your rules. Rules can look at things like IP addresses, countries, and patterns such as SQL
injection and cross-site scripting, which are common attacks on web applications.

### AWS Shield

**AWS Shield** protects against distributed denial of service (DDoS) attacks, which try to overwhelm a
system with traffic.

### AWS Firewall Manager

**AWS Firewall Manager** manages protections centrally across accounts and resources, including AWS WAF
rules, Shield Advanced, and security groups. New accounts and resources receive the protections
automatically.

## Finding problems

### Amazon GuardDuty

**Amazon GuardDuty** is a threat detection service. It analyses data sources such as AWS CloudTrail
events, VPC Flow Logs, and DNS logs, looking for signs of malicious activity. It reports what it finds as
findings.

### Amazon Inspector

**Amazon Inspector** is a vulnerability management service. It automatically scans Amazon EC2 instances,
container images, and AWS Lambda functions for software vulnerabilities and unintended network exposure.

<ImportantConcept>
  GuardDuty looks for **active threats** in your activity. Inspector looks for **weaknesses** in
  your software, before someone exploits them.
</ImportantConcept>

### AWS Security Hub

**AWS Security Hub** gives you a view of your security state across accounts. It collects findings from
services such as GuardDuty and Inspector, and it runs checks against security standards. Its documentation
now uses the name AWS Security Hub CSPM for this capability, where CSPM stands for cloud security posture
management.

### AWS Trusted Advisor

**AWS Trusted Advisor** inspects your environment and recommends improvements, including ways to close
security gaps. Security is one of its check categories, along with areas like cost optimization and
performance. Which checks you can use depends on your support plan.

<CostWarning>
  Several of these services have their own charges, and some offer a limited free trial. AWS Shield
  Standard is included at no extra cost. Check each service's pricing before you turn it on.
</CostWarning>

## Third-party products and security information

**AWS Marketplace** is a catalog of third-party software, including security products such as firewalls
and antivirus tools. You can buy and deploy them through it.

To learn more about security on AWS, use these official resources:

- **AWS Security Center**, the main landing page for AWS security information.
- **AWS Security Blog**, for articles on current security topics.
- **AWS Knowledge Center**, for answers to common questions.

<RealWorldExample title="Real-world example: an online store under attack">
  A Bloemfontein online store sees a sudden flood of traffic. AWS Shield Standard is already
  protecting it against common network attacks. The team adds AWS WAF rules to block malicious web
  requests. Amazon GuardDuty then flags unusual activity from one account, and AWS Security Hub
  shows the team everything in one place.
</RealWorldExample>

## What the exam expects

<ExamTip>
  **DDoS** points to AWS Shield. **SQL injection or web requests** points to AWS WAF. **Malicious
  activity** points to Amazon GuardDuty. **Software vulnerabilities** points to Amazon Inspector.
  **Central view of findings** points to AWS Security Hub.
</ExamTip>

## Common misconceptions

- **"Shield Standard needs to be turned on."** It is included automatically.
- **"GuardDuty and Inspector do the same thing."** One detects threats, the other finds vulnerabilities.
- **"AWS WAF stops every kind of attack."** It inspects HTTP and HTTPS requests. Other layers need other
  protections.

- AWS Security Hub brings findings together, and Trusted Advisor recommends improvements.
