## The idea in plain language

Think about three ways to store things. A warehouse hands over whole boxes by label. A hard drive plugged
into one computer lets it change any small part quickly. A shared office cabinet lets many people open
the same folders.

These match the three types of cloud storage: **object**, **block**, and **file**.

## Amazon S3: object storage

**Amazon Simple Storage Service (Amazon S3)** stores objects in **buckets**, each identified by a key.
Uses include data lakes, websites, backup and restore, and archives. Buckets and objects are private by
default.

### Storage classes

Different data needs different handling. S3 storage classes trade access speed and resilience against
cost.

### Lifecycle policies

An **S3 Lifecycle** configuration automates what happens to objects over time. **Transition** actions
move objects to a cheaper class, and **expiration** actions delete them. For example, you might move logs
to S3 Standard-IA after 30 days and archive them after a year.

## Block storage

**Amazon Elastic Block Store (Amazon EBS)** provides volumes that attach to EC2 instances and work like a
local disk. **Snapshots** are point-in-time backups of a volume.

**Instance store** is temporary block storage on disks physically attached to the host. It suits buffers,
caches, and scratch data. Data survives a reboot, but it is lost when the instance stops, hibernates, or
terminates, or if the disk fails.

<ImportantConcept>
  EBS volumes persist separately from an instance. Instance store is temporary, so never keep the
  only copy of important data there.
</ImportantConcept>

## File storage

**Amazon Elastic File System (Amazon EFS)** is serverless, elastic file storage using the Network File
System (NFS) protocol. It scales automatically and can be shared by many instances. Its documentation
says it is not supported with Windows EC2 instances.

**Amazon FSx** provides fully managed file systems built on popular technologies: FSx for Windows File
Server, FSx for Lustre (for high-performance workloads), FSx for NetApp ONTAP, and FSx for OpenZFS.

## Hybrid storage and backup

**AWS Storage Gateway** connects on-premises environments to AWS storage. Cached volumes keep frequently
used data locally and store the rest in Amazon S3, which is why the exam calls this a cached file system
option.

**AWS Backup** is a centralised, policy-based backup service across AWS services. It suits organisations
that want one place to manage backups for resources such as Amazon EBS, Amazon RDS, and Amazon EFS.

<CostWarning>
  Cheaper storage classes can add retrieval fees and minimum storage durations, so the lowest
  storage price is not always the lowest total cost. Lifecycle transitions also carry request
  charges.
</CostWarning>

<RealWorldExample title="Real-world example: a medical imaging company">
  A Bloemfontein imaging company keeps new scans in S3 Standard, because doctors view them often. A
  lifecycle policy moves them to S3 Glacier Instant Retrieval later, because they are rarely needed
  but must open quickly. AWS Backup manages backups of its databases from one place.
</RealWorldExample>

## What the exam expects

<ExamTip>
  **Unknown access patterns** points to S3 Intelligent-Tiering. **Long-term archive** points to S3
  Glacier classes. **Disk for one EC2 instance** points to Amazon EBS. **Shared Linux file system**
  points to Amazon EFS. **Windows file shares** points to FSx for Windows File Server. **On-premises
  access to cloud storage** points to AWS Storage Gateway.
</ExamTip>

## Common misconceptions

- **"S3 is a disk for my server."** It is object storage. Amazon EBS is the disk.
- **"Instance store data survives a stop."** It does not.
- **"One Zone-IA is as resilient as Standard-IA."** It keeps data in a single Availability Zone.

## Summary

<LessonSummary>

- Amazon S3 is object storage, with classes for different access needs.
- Lifecycle policies move or delete objects automatically.
- Amazon EBS is persistent block storage, and instance store is temporary.
- Amazon EFS and Amazon FSx provide file storage.
- AWS Storage Gateway connects on-premises systems to AWS storage, and AWS Backup centralises backups.

</LessonSummary>
