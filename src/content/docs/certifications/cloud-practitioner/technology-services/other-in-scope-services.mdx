## The idea in plain language

A large company has many departments that are easy to overlook, such as the mailroom, the call center,
and the workshop. This lesson is a tour of those departments on AWS. For each service, learn what it is
for. The exam does not expect detail beyond that.

## Messaging and integration

Applications often need to pass messages. **Decoupling** means components communicate without depending
directly on each other, so one can fail or slow down without breaking the rest.

<ImportantConcept>
  **Amazon SNS** pushes one message to **many** subscribers, including email and SMS. **Amazon SQS**
  holds messages until a consumer **pulls** one to process it.
</ImportantConcept>

## Business applications

- **Amazon Connect** is a cloud contact center for voice, chat, and SMS. Its documentation now calls this
  Amazon Connect Customer, within a wider Amazon Connect family.
- **Amazon Simple Email Service (Amazon SES)** sends and receives email from your own domains.

For help from AWS itself, customers use **AWS Support**, covered in the
[support lesson](/certifications/cloud-practitioner/billing-support/support-and-technical-resources/).

## End-user computing

These services present desktops and applications to people on their own devices.

- **Amazon WorkSpaces** provides virtual desktops in the cloud.
- **Amazon AppStream 2.0** streams desktop applications to users. Its documentation now uses the name
  WorkSpaces Applications, so you may see either name.
- **Amazon WorkSpaces Secure Browser** gives users secure browser access to websites and web applications.

## Frontend web and mobile

**AWS Amplify** helps developers build, deploy, and host web and mobile applications.

## Internet of Things

**AWS IoT Core** connects devices to AWS so that they can send and receive messages. The **Internet of
Things (IoT)** means everyday physical devices, such as sensors, connected to a network.

<RealWorldExample title="Real-world example: a smart farm">
  A Free State farm fits soil sensors that connect through AWS IoT Core. When moisture falls too
  low, an event triggers an Amazon SNS notification to the farm manager. Readings wait in an Amazon
  SQS queue until the processing application handles them, so a busy period loses nothing.
</RealWorldExample>

## What the exam expects

<ExamTip>
  **Send alerts to many subscribers** means Amazon SNS. **Queue, or decouple** means Amazon SQS.
  **Bulk email** means Amazon SES. **Contact center** means Amazon Connect. **Virtual desktop**
  means Amazon WorkSpaces. **Stream an application** means AppStream 2.0. **Connect devices** means
  AWS IoT Core.
</ExamTip>

## Common misconceptions

- **"Amazon SNS and Amazon SES are the same."** SNS is a general notification service. SES is for email.
- **"Amazon SQS sends messages to many subscribers."** A queue message is typically processed by one
  consumer, then deleted.
- **"WorkSpaces and AppStream 2.0 are identical."** One gives a whole desktop, the other streams
  applications.

## Try it yourself (optional)

You need no AWS account for this, and it costs nothing. Think about an online order. Write down the steps
that happen after payment. Decide where a queue would help, and where a notification would.

## Summary

<LessonSummary>

- Amazon SNS publishes to subscribers, and Amazon SQS queues messages.
- Amazon Connect is a contact center, and Amazon SES handles email.
- AWS CodeBuild, CodePipeline, and X-Ray support building, delivering, and troubleshooting.
- WorkSpaces, AppStream 2.0, and WorkSpaces Secure Browser deliver desktops and applications.
- AWS Amplify supports web and mobile apps, and AWS IoT Core connects devices.

</LessonSummary>
