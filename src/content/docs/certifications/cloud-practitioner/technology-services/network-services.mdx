## The idea in plain language

A gated housing estate has its own private roads. A main gate connects it to the public road. Some houses
face the entrance, and others sit deep inside with no direct access from outside. Guards check people at
the gate, and each house has its own lock.

A **virtual private cloud (VPC)** is your private estate on AWS.

## Components of a VPC

**Amazon Virtual Private Cloud (Amazon VPC)** gives you a logically isolated virtual network.

- A **subnet** is a range of IP addresses within one Availability Zone.
- A **route table** controls where network traffic goes.
- An **internet gateway** connects a VPC to the internet.
- A **public subnet** has a route to an internet gateway. A **private subnet** does not.
- A **NAT gateway** can give resources in private subnets outbound internet access.

AWS recommends security groups as your primary control, with network ACLs as a secondary layer.

<ImportantConcept>
  A network ACL is the estate gate, for the whole subnet. A security group is the lock on each
  house, for each instance.
</ImportantConcept>

**Amazon Inspector** also helps here. It scans for unintended network exposure as well as software
vulnerabilities.

## Amazon Route 53

**Amazon Route 53** is a highly available Domain Name System (DNS) service. DNS translates names such as
example.com into the addresses that computers use. Route 53 has three main functions: domain
registration, DNS routing, and health checks.

<RealWorldExample title="Real-world example: a bank's branch system">
  A Sandton bank puts its customer-facing website in a public subnet and its database in a private
  subnet. Staff at head office reach internal systems over AWS Direct Connect, with a Site-to-Site
  VPN as a backup. Route 53 sends customers to the website.

## What the exam expects

<ExamTip>
  **Instance-level firewall** means security group. **Subnet-level firewall, or explicit deny**
  means network ACL. **DNS** means Amazon Route 53. **Dedicated private connection** means AWS
  Direct Connect. **Encrypted over the internet** means VPN.
</ExamTip>

## Common misconceptions

- **"A subnet can span Availability Zones."** A subnet sits within a single Availability Zone.
- **"Security groups can deny traffic."** They only allow. Anything not allowed is blocked.
- **"Direct Connect runs over the public internet."** It is a dedicated private connection.

## Summary

<LessonSummary>

- A VPC is a logically isolated virtual network, divided into subnets.
- An internet gateway connects a VPC to the internet.
- Security groups protect instances and are stateful. Network ACLs protect subnets and are stateless.
- Amazon Route 53 provides DNS.
- AWS VPN runs over the internet. AWS Direct Connect is a dedicated private connection.

</LessonSummary>
