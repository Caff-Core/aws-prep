The AWS Certified Cloud Practitioner exam checks that you understand what the AWS Cloud is, how it
is secured, what its core services do, and how it is paid for. It suits people in technical and
non-technical roles. AWS does not expect coding, architecture design, or troubleshooting skills at
this level.

The curriculum below covers every task statement in the official exam guide. Lessons were checked
against official AWS sources, and independent human review is still in progress.

<StudyProgress certificationId={certificationId} />

## Who this course is for

Anyone new to the cloud. AWS suggests up to 6 months of exposure to the AWS Cloud, but says this is
not required, and this course starts from first principles.
