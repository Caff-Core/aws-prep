# Roadmap

Work is tracked in [GitHub issues](https://github.com/Caff-Core/aws-prep/issues) by milestone.

1. **Foundation.** Platform, design system, data model, and core components.
2. **Cloud Practitioner experience.** Full curriculum map, practice mode, and review of the sample
   lesson.
3. **Content production.** Lessons for all four domains, one topic at a time.
4. **Assessment and revision.** Mock exams, dashboards, weak-area analysis, and optional accounts.
5. **Additional certifications.** New paths on the shared framework.
